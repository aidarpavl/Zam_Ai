# Zam AI — цифровой помощник заместителя директора школы

Python/Streamlit-версия Zam AI: каталог из 19 управленческих задач, конструктор промтов по модели
«Рөл–Нысан–Логика–Нәтиже–Контекст», модуль «Excel → анализ» с 11 профилями, архив анализов и реестр
управленческих решений. Интерфейс — на казахском языке.

## Структура

```
app.py                  # Streamlit-интерфейс (6 страниц)
zam_core/
  tasks.py              # каталог задач, «Алтын қаңқа», 5 уровней
  analyzers.py          # распознавание столбцов, автопрофиль, 11 анализаторов
  excel_io.py           # чтение XLSX/CSV, поиск строки заголовка, проверка персональных данных
  prompts.py            # промты, аналитическая справка, экспорт DOCX/CSV
examples/zam_ai_demo.xlsx  # демо-книга: 6 листов под разные профили
.streamlit/config.toml  # тема и лимит загрузки
requirements.txt
```

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Публикация с GitHub (Streamlit Community Cloud)

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (включая скрытую папку `.streamlit`).
   ```bash
   git init && git add . && git commit -m "Zam AI"
   git branch -M main
   git remote add origin https://github.com/<логин>/zam-ai.git
   git push -u origin main
   ```
2. Откройте https://share.streamlit.io, войдите через GitHub и нажмите **Create app**.
3. Выберите репозиторий, ветку `main`, главный файл `app.py` → **Deploy**.
4. Через пару минут приложение будет доступно по ссылке вида `https://<имя>.streamlit.app`.

## Что изменилось по сравнению с HTML-версией

- **Хранение.** Вместо `localStorage` браузера данные живут в сессии Streamlit. Чтобы не потерять анализы
  и решения, на странице «Пилоттық панель» есть экспорт/импорт всего рабочего пространства в JSON
  (импорт также принимает старый JSON-экспорт анализов).
- **Обработка файлов.** В облаке файл обрабатывается на сервере приложения и не сохраняется. Для полностью
  локальной обработки запустите приложение на своём компьютере.
- **Справка** скачивается как настоящий Word (`.docx`, с таблицей расчётов в приложении) и как TXT.
  Кнопка «Басып шығару» заменена скачиванием DOCX.
- **Копирование промта** — кнопка в правом верхнем углу блока с промтом.
- **Реестр решений** — редактируемая таблица: правьте поля и статус, отмечайте «Жою» и нажимайте
  «Өзгерістерді сақтау».
- **Профиль школы** (название, регион) задаётся в боковой панели и подставляется в промты.
- Поддерживаются `.xlsx`, `.xlsm`, `.csv` (UTF-8 или Windows-1251, разделитель `;`, `,` или Tab).
  Старый `.xls` нужно пересохранить в `.xlsx`.

Логика расчётов (качество, успеваемость, СОУ, дельта БЖБ/ТЖБ, охват, динамика и т. д.) перенесена
из JS один в один; демо-данные дают те же цифры (качество 53,8%, успеваемость 98,7%, СОУ 55,9%).
